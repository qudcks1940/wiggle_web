# Wiggle AI 그림책 편집기 제품·구현 명세

## 1. 결정 요약

Wiggle의 기존 학생용 그림 캔버스는 그대로 유지한다. 그림책은 완성 작품을 수정하는 기능이 아니라, 완성 작품과 새 이미지를 자산으로 불러와 글·배경·장식 요소와 함께 여러 페이지에 배치하는 별도 비파괴 편집기로 만든다.

- 기존 `DrawDocument`, 자동 저장, 질문 전후 버전, 타임랩스와 완성 PNG는 변경하지 않는다.
- 완성 작품은 그림책에서 잠긴 원본 이미지 자산으로 사용한다.
- 그림책의 페이지·텍스트·이미지·배경·레이어는 별도 `StorybookDocument`로 저장한다.
- 학생이 직접 쓴 글이 항상 최종 원본이다. AI는 요청받은 경우에만 문장이나 이미지 후보를 제안하고 자동 덮어쓰기하지 않는다.
- Canva 전체 제품을 복제하지 않는다. 그림책 제작에 필요한 Canva형 편집 기능과 Heyzine형 읽기 경험을 Wiggle 안에서 완결한다.

## 2. 참고 작업에서 확인한 제작 흐름

공개된 Padlet·Canva 자료와 Heyzine 결과물에서 다음 흐름을 확인했다.

1. 스케치북에서 그림을 그리고 레이어와 라인 드로잉을 익힌다.
2. Canva에서 요소를 검색해 음식·가구·파티용품처럼 장면을 꾸민다.
3. 텍스트 상자를 넣고 초대 이유·장소·날짜·시간처럼 직접 글을 쓴다.
4. 요소를 이동·정리하고 필요 없는 항목을 삭제한다.
5. 좋은 그림책의 특징, 마인드맵, 구성안, 스토리보드를 거쳐 여러 페이지를 완성한다.
6. PDF를 Heyzine으로 옮겨 페이지 넘김, 확대, 전체 화면, 소리와 페이지 이동이 있는 플립북으로 공유한다.

이 흐름을 Wiggle에서는 `그리기 → 내 그림 보관함 → 그림책 만들기 → 페이지 편집 → 미리 보기 → PDF/플립북 공유`로 단축한다.

## 3. 사용자 흐름

### 3.1 완성 그림에서 시작

1. 학생이 `/student/archive/[artworkId]`에서 완성 그림을 연다.
2. `📖 그림책에 넣기`를 누른다.
3. 기존 그림책을 고르거나 새 그림책을 만든다.
4. 선택한 그림은 새 페이지의 잠긴 이미지 요소로 들어간다.
5. 원본 그림을 바꾸지 않고 위치·크기·자르기·투명도만 구성 문서에 저장한다.

### 3.2 빈 그림책에서 시작

1. `/student/books`에서 `새 그림책`을 누른다.
2. 제목과 판형을 고른다.
3. 표지와 첫 페이지가 생성된다.
4. `내 그림`, `새 이미지`, `AI 이미지`, `글`, `배경`, `요소` 중 하나를 추가한다.

### 3.3 완성하고 읽기

1. 페이지 순서를 정하고 `미리 보기`를 연다.
2. 오류가 없는지 확인한 뒤 `완성`을 누른다.
3. 페이지 PNG와 PDF를 생성한다.
4. Wiggle 플립북에서 넘겨 읽거나 승인된 제한 링크로 공유한다.

## 4. 편집기 화면

### 4.1 기본 구조

- 왼쪽 또는 아래: 페이지 썸네일 목록
- 가운데: 현재 페이지 작업 영역
- 오른쪽 또는 하단 시트: 선택한 요소의 속성
- 상단: 뒤로, 제목, 저장 상태, 실행 취소/다시 실행, 미리 보기, 완성
- 요소 추가 메뉴: 내 그림, 업로드, AI 이미지, 글, 배경, 도형·스티커

태블릿·데스크톱에서는 세 영역을 동시에 보여 주고, 휴대전화에서는 페이지 목록과 속성 패널을 바텀시트로 전환한다.

### 4.2 페이지

필수 기능:

- 표지, 일반 페이지, 뒤표지
- 페이지 추가, 복제, 삭제, 순서 변경
- 페이지 썸네일과 현재 위치 표시
- 세로, 가로, 정사각형 판형
- 프로젝트 생성 뒤 판형 변경 시 `맞춤`, `채우기`, `그대로 두기` 중 선택
- 최대 24페이지, 페이지당 최대 50개 요소를 1차 안전 한도로 사용

### 4.3 요소 공통 조작

모든 요소는 다음 공통 필드를 가진다.

- 위치 `x`, `y`
- 크기 `width`, `height`
- 회전 `rotation`
- 쌓임 순서 `zIndex`
- 투명도 `opacity`
- 잠금 `locked`
- 표시 여부 `visible`

필수 조작:

- 선택, 끌어서 이동, 모서리 크기 조절, 회전
- 복제, 삭제, 잠금/잠금 해제
- 맨 앞으로, 앞으로, 뒤로, 맨 뒤로
- 가로·세로 가운데와 페이지 가장자리 맞춤
- 이동 중 정렬 안내선과 안전 여백 표시
- 실행 취소와 다시 실행
- 터치 손잡이 최소 44px

그림과 글은 시각적으로 다른 선택 테두리와 아이콘을 사용하고, 레이어 목록에서도 종류를 명확히 표시한다.

## 5. 그림·이미지 기능

### 5.1 내 그림

- 완성 작품과 그리는 중인 작품을 구분해 표시한다.
- 기본값은 완성 작품만 선택 가능하게 한다.
- `final_image_key`가 가리키는 정확한 1024×1024 PNG를 자산으로 등록한다.
- 그림책에 넣은 뒤 원본 작품이 삭제·보관되더라도 책의 승인된 스냅샷은 유지한다.
- 원본 픽셀을 AI가 자동 수정하거나 다시 그리지 않는다.

### 5.2 새 이미지 업로드

- 기기 사진·파일에서 JPEG, PNG, WebP를 추가한다.
- 파일 확장자가 아니라 실제 콘텐츠 형식을 검사한다.
- 이미지 메타데이터를 제거하고 안전한 형식으로 다시 인코딩한다.
- 권장 최대 10MB, 최대 변 길이 4096px로 제한한다.
- 원본 파일은 R2에, 소유권·크기·형식·해시는 D1에 저장한다.

### 5.3 이미지 편집

1차 필수:

- 맞춤/채우기, 자르기 위치, 크기, 회전, 좌우 반전, 투명도
- 배경 이미지로 지정
- 다른 이미지로 교체하되 위치와 크기 유지

후속 기능:

- 밝기, 대비, 채도와 제한된 필터
- 배경 제거
- 프레임·마스크
- 이미지 일부 지우기와 생성형 채우기

생성형 편집은 학생 원본 그림의 보존 원칙과 별도이며, 새 복제 자산에서만 실행한다.

## 6. 글 기능

필수 기능:

- 제목, 본문, 짧은 설명, 말풍선 텍스트 상자
- 직접 입력과 기기 받아쓰기
- 글꼴, 크기, 색, 굵게, 기울임, 밑줄
- 왼쪽/가운데/오른쪽 정렬
- 글자 간격, 줄 간격, 상자 내부 여백
- 글상자 이동, 크기 조절, 회전, 복제, 삭제
- 긴 글의 넘침 경고와 자동 맞춤 선택
- 밝은 배경에서 대비가 부족하면 경고

초기 한국어 글꼴은 재배포 라이선스와 Cloudflare 환경을 확인한 제한 목록만 제공한다. Canva의 글꼴·템플릿·스티커를 복사하지 않는다.

## 7. 배경·요소 기능

### 7.1 배경

- 단색과 제한된 그라데이션
- 내 그림 또는 업로드 이미지를 배경으로 사용
- Wiggle이 권리를 보유한 교실용 배경 모음
- 요청 시 AI 배경 생성
- 배경 맞춤/채우기와 초점 위치 조절

### 7.2 요소

- Wiggle 기본 도형, 선, 화살표, 말풍선, 프레임
- 권리 확인된 스티커·아이콘
- 검색, 최근 사용, 즐겨찾기
- 색 변경이 허용된 벡터 요소만 색 편집

외부 스톡 검색은 라이선스·검색 API·아동 안전 필터를 확정한 뒤 별도 단계로 둔다.

## 8. AI 기능

AI는 별도 버튼을 눌렀을 때만 작동한다.

### 8.1 이야기 도움

- 주제에서 4~8페이지 구성안 제안
- 현재 페이지에 들어갈 짧은 문장 후보 3개
- 학생이 쓴 문장을 유지한 채 맞춤법만 확인
- 어려운 문장을 저학년 말로 바꾸는 후보 제안
- 제목 후보와 다음 장면 질문

AI 제안은 항상 `그대로 쓰기`, `조금 고치기`, `사용하지 않기`를 제공하며 자동 저장 본문을 덮어쓰지 않는다.

### 8.2 이미지 도움

- 새 배경 또는 새 삽화 생성
- 페이지 판형에 맞춘 가로·세로 후보
- 한 번에 소수 후보만 만들고 사용자가 선택한 결과만 책에 추가
- 생성 이미지임을 자산 메타데이터에 기록
- 학생 원본 그림의 화풍 복제나 원치 않는 변형은 기본 제공하지 않음

### 8.3 안전 경계

- 학생·교실 식별정보를 프롬프트에 자동 포함하지 않는다.
- 생성 전 입력 검증, 생성 후 이미지·텍스트 안전 검사를 둔다.
- 교사 또는 학생의 명시적 선택 없이 공개하지 않는다.
- AI 오류와 대기 실패가 직접 작성·업로드·저장 기능을 막지 않아야 한다.

## 9. 내보내기와 플립북

### 9.1 내보내기

- 페이지별 고해상도 PNG
- 인쇄·공유용 PDF
- 표지 썸네일
- 내보낸 결과와 해당 `storybookRevision`을 연결해 재현 가능하게 저장
- 편집 중인 최신 버전과 마지막 성공 내보내기를 구분

PDF 생성 실패 시 편집 문서는 그대로 보존하고 다시 시도할 수 있어야 한다.

### 9.2 Wiggle 플립북 뷰어

필수 기능:

- 한 장/두 장 보기
- 이전·다음 버튼, 페이지 슬라이더, 썸네일 목차
- 터치 스와이프와 키보드 화살표
- 확대/축소, 전체 화면
- 페이지 넘김 효과와 `동작 줄이기` 대응
- 페이지 소리 켜기/끄기
- 모바일·태블릿·데스크톱 반응형
- 읽기 링크, QR 코드와 임베드 가능한 읽기 전용 화면

후속 기능:

- 페이지별 녹음·배경 음악
- 링크, 영상, 오디오, GIF 같은 상호작용 요소
- 책갈피, 방문·페이지 열람 통계

Heyzine은 선택적 PDF 연동 대상으로 둘 수 있지만, 핵심 읽기 기능은 외부 서비스 없이 Wiggle 안에서 동작해야 한다.

## 10. 저장 모델

### 10.1 D1

#### `storybooks`

- `id`, `student_id`, `classroom_id`
- `title`, `format`, `status`
- `revision`, `last_mutation_id`
- `cover_page_id`, `page_count`
- `created_at`, `updated_at`, `completed_at`

#### `storybook_pages`

- `id`, `storybook_id`, `position`, `kind`
- `scene_json`, `scene_version`
- `thumbnail_key`, `rendered_image_key`
- `created_at`, `updated_at`

#### `storybook_assets`

- `id`, `student_id`, `storybook_id`
- `source_type`: `artwork`, `upload`, `ai`, `wiggle`
- `source_artwork_id`, `object_key`
- `content_type`, `width`, `height`, `byte_size`, `sha256`
- `alt_text`, `provenance_json`
- `created_at`

#### `storybook_exports`

- `id`, `storybook_id`, `storybook_revision`
- `format`, `status`, `object_key`, `error_code`
- `created_at`, `completed_at`

#### `storybook_share_links`

- 원문 토큰이 아닌 토큰 해시
- 책, 소유 학생, 발급 교사, 만료·취소 시각
- 보호자 동의 확인 기록과 공개 범위

### 10.2 R2

- 업로드 이미지와 안전하게 재인코딩한 사본
- AI 생성 이미지
- 페이지 썸네일과 고해상도 렌더
- PDF와 공유용 표지
- 필요 시 버전별 `StorybookDocument` 스냅샷

### 10.3 `StorybookDocument`

```ts
type StorybookDocument = {
  schemaVersion: 1;
  page: { width: number; height: number; background: Background };
  elements: Array<{
    id: string;
    type: "image" | "text" | "shape" | "sticker";
    x: number;
    y: number;
    width: number;
    height: number;
    rotation: number;
    zIndex: number;
    opacity: number;
    locked: boolean;
    visible: boolean;
    assetId?: string;
    text?: TextStyle & { value: string };
    crop?: { x: number; y: number; scale: number };
    shape?: ShapeStyle;
  }>;
};
```

클라이언트가 보낸 JSON을 그대로 신뢰하지 않고 서버에서 버전, 필드, 좌표, 크기, 문자열 길이, 요소 수와 전체 바이트 상한을 검증한다.

## 11. API 경계

- `GET/POST /api/storybooks`
- `GET/PUT /api/storybooks/[id]`
- `POST /api/storybooks/[id]/pages`
- `PUT/DELETE /api/storybooks/[id]/pages/[pageId]`
- `POST /api/storybooks/[id]/assets/from-artwork`
- `POST /api/storybooks/[id]/assets/upload`
- `POST /api/storybooks/[id]/assets/generate`
- `GET /api/storybooks/[id]/assets/[assetId]`
- `POST /api/storybooks/[id]/export`
- `GET /api/storybooks/[id]/exports/[exportId]`
- `POST /api/storybooks/[id]/share`

모든 쓰기 요청은 `sameOrigin`, 학생 세션 소유권, 요청 속도 제한, `mutationId`, `expectedRevision`을 검사한다. 객체 ID만 알고 있는 다른 학생·학급·교사는 원본 이미지와 구성 문서를 읽을 수 없어야 한다.

## 12. 저장·오프라인·충돌

- 요소 조작 중에는 로컬 편집 상태를 즉시 반영한다.
- 입력 종료 뒤 짧은 debounce와 최대 대기 시간으로 자동 저장한다.
- 네트워크 단절 시 IndexedDB에 페이지별 변경을 보관한다.
- 재연결 시 `expectedRevision`을 기준으로 순서대로 전송한다.
- 같은 책이 다른 탭에서 바뀌면 무조건 덮어쓰지 않고 `서버 버전 열기`, `내 버전을 사본으로 저장`을 제공한다.
- 느린 저장 중 연속 탭·페이지 이동·완성을 눌러도 중복 페이지나 유실이 없어야 한다.

## 13. 권한과 공유

- 학생은 자기 책과 자기 자산만 편집한다.
- 교사는 학급 학생 책을 읽기 전용으로 보고, 과제·템플릿을 배포하고, 제출 상태를 관리한다.
- 교사가 학생 책을 직접 수정하는 기능은 별도 명시적 공동편집 권한 없이는 제공하지 않는다.
- 가족 공유는 기존 보호자 사전 동의 기록과 제한 링크 정책을 재사용한다.
- 새 책은 비공개가 기본이며 링크 발급 전에는 외부에서 접근할 수 없다.
- 공유 취소·학생 보관 처리 후에도 기존 토큰으로 접근할 수 없어야 한다.

## 14. 단계별 구현

### 1단계: 세로 기능 조각

- 완성 그림 상세에서 `그림책에 넣기`
- 새 책과 한 페이지 생성
- 그림 한 장과 직접 쓴 글상자 추가
- 이동·크기·앞뒤 순서·삭제
- 자동 저장, 다시 열기, 단일 페이지 PNG 미리 보기

이 단계가 실제 모바일 브라우저에서 통과하기 전에는 기능을 넓히지 않는다.

### 2단계: 다중 페이지 편집기

- 표지와 여러 페이지
- 페이지 추가·복제·삭제·순서 변경
- 배경, 도형, 스티커, 업로드 이미지
- 자르기, 회전, 투명도, 잠금, 정렬선
- 페이지 PNG와 PDF

### 3단계: 읽기·공유

- Wiggle 플립북 뷰어
- 한 장/두 장 보기, 넘김, 확대, 전체 화면, 목차
- 제한 공유 링크와 QR
- 교사 제출·승인 흐름

### 4단계: AI

- 이야기 구성과 문장 후보
- 새 삽화·배경 생성
- 생성 이력, 안전 검사, 실패 복구
- 사용자가 승인한 결과만 책에 반영

### 5단계: 고급 편집

- 배경 제거, 필터, 마스크·프레임
- 음성 녹음, 배경 음악, 링크·영상
- 교사 템플릿과 과제 복제
- 읽기 통계와 책장

## 15. 1단계 독립 검증 기준

1. 완성 그림에서 책을 만들면 저장된 최종 PNG와 픽셀이 달라지지 않는다.
2. 원본 작품은 그림책 편집 뒤에도 `DrawDocument`, 타임랩스, 완성 이미지가 변하지 않는다.
3. 글상자를 직접 입력하고 그림과 독립적으로 이동·크기 조절·앞뒤 배치할 수 있다.
4. 글과 그림은 레이어 목록에서 종류와 이름이 구분된다.
5. 새로고침과 재로그인 뒤 같은 위치·크기·글 내용으로 복원된다.
6. 20회 이상의 빠른 이동·크기 조절 뒤 마지막 상태가 저장된다.
7. 저장이 느릴 때 페이지를 닫아도 기기 보관 상태를 알리고 재연결 뒤 복구한다.
8. 다른 학생 ID, 다른 학급 ID, 추측한 자산 ID로 읽기·수정·삭제할 수 없다.
9. 320×568, 390×844, 844×390에서 작업 영역과 저장·뒤로 버튼이 잘리지 않는다.
10. 터치, 키보드, 화면 확대, `prefers-reduced-motion`에서 핵심 흐름을 끝낼 수 있다.
11. 서버가 거부한 장면 문서·과대 업로드·잘못된 이미지가 R2 고아 객체로 남지 않는다.
12. AI와 내보내기 실패가 직접 글쓰기와 기존 저장 데이터를 손상시키지 않는다.

## 16. 의도적으로 제외하는 범위

다음은 “Canva의 모든 기능”에 포함될 수 있지만 그림책 1차 제품의 필수 조건이 아니다.

- 동영상 타임라인과 고급 애니메이션 편집
- 웹사이트·문서·스프레드시트·프레젠테이션 전체 제작 도구
- 실시간 다중 사용자 공동편집과 댓글
- 브랜드 키트, 소셜 예약 게시, 인쇄 주문
- Canva 앱 마켓 전체와 외부 앱 호환
- Canva의 독점 템플릿·글꼴·스톡 이미지·스티커 복제

이 범위를 처음부터 포함하면 현재 저학년 그림 경험과 저장 안정성을 해치므로, 실제 수업에서 필요한 사례가 확인될 때 독립 기능으로 추가한다.

## 17. 기존 설계와의 관계

이 명세는 `docs/editor-roadmap.md`의 “완성 후 이야기·공유 카드 꾸미기”를 여러 페이지 그림책 제품으로 확장한다. 핵심 그림 캔버스에 범용 선택 도구와 외부 편집기를 넣지 않는다는 기존 결정은 유지한다.
