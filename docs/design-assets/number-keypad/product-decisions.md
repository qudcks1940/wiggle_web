# 2026-09-09 사용자 디자인 결정 — 자기 번호 입력

사용자 원문: “2번으로 만들고 싶어, 필요한 에셋을 뽑아줄래?”

- 선택 정본: `reference/selected-option-2.png`.
- 대상은 `/join`의 학생 자기 번호 입력 화면이다. 큰 숫자 키패드를 스프링 스케치북 안에 배치하고, 왼쪽에는 몽그리가 책상에 양손을 올린다.
- 색상은 초록·크림에 노란 주 행동 버튼. 노란 오리의 파란 베레모·스카프는 유지한다.
- 번호·글자·버튼은 구현용 HTML/CSS로 분리하고 장면은 텍스트 없는 에셋으로 전달한다.
- 요청 범위는 에셋 제작과 Claude 전달 자료이며 앱 구현·검증·커밋·배포를 완료한 것은 아니다.
- 모바일 상세 배치와 토큰은 전달 가이드의 제안이며 추가 사용자 결정으로 기록하지 않는다.

구현 담당자는 이 결정을 저장소 `docs/product-decisions.md`에 합치고 실제 구현/검증 상태를 `docs/current-state.md`에 기록한다. 공유 폴더의 다른 에이전트 브랜치와 추적 문서는 이 에셋 전달 작업에서 수정하지 않았다.
