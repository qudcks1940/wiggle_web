위글 색 테마 · 2차 시안 (1번 ~ 5번)

1차(크림·여백형)는 폐기. 2차는 Study.Pilot에서 캐릭터 마스코트 · 꽉 찬 화면 · 입체(3D) 질감을 가져오고, Learnify / EduLearn에서 중성적이고 따뜻한 색감과 교사 화면의 어른스러운 톤을 가져왔습니다. Study.Pilot의 채도 높은 파란 배경은 가져오지 않았습니다.

다섯 안은 색상만 다른 게 아니라 화면의 성격(레지스터)이 다릅니다. 조용한 크림 안은 1차에서 이미 봤으므로 여기에는 없습니다. 다섯 안 모두 "꽉 차고 활기찬" 쪽입니다. 의견 주실 땐 3번의 교사 화면 처럼 번호로 불러 주세요.

성별 중립 — 지배색이 하늘색도 분홍도 아닙니다. 자두·숲·테라코타·가지·먹빛을 앵커로 씁니다.
아이 그림이 주인공 — (b) 그리기 화면은 흰 도화지가 화면 대부분입니다. 이게 이번 시안의 진짜 시험입니다.
점수·등수 없음 — 빨강=틀림, 초록=맞음 의미를 만들지 않습니다.
안 그린 쪽 — 빠진 회차는 경고색이 아니라 전용 중립 토큰으로 "아직 안 그린 쪽"이 됩니다.

다섯 안이 공통으로 지킨 것 — 지배색이 하늘색도 분홍도 아님 / 빨강·초록에 정답·오답 의미 없음 / "아직 안 그린 쪽"은 전용 중립 토큰으로 경고색 아님 / 선택 상태는 색 + 테두리 + 아래 점 + 글자 4중 표시 / 교사 화면은 같은 색 가족의 더 어두운 앵커 + 흰 버튼으로 어른 톤을 만듦 / 흰 도화지는 어떤 안에서도 화면에서 가장 밝은 면.

고르실 때 기준 — 아이 그림 보호만 보면 4번 > 1번 = 2번 > 5번 > 3번, 교사 화면의 어른스러움만 보면 5번 > 2번 > 4번 > 1번 > 3번, 그리미 캐릭터가 가장 살아나는 건 4번과 2번입니다.
