# 교사 학급 작업공간 디자인 기준

- `selected-today.png`: 사용자가 선택한 1번 `오늘 수업` 시안.
- `selected-works-books.png`: 같은 방향으로 만든 `작품·그림책` 시안.
- `selected-roster-settings.png`: 같은 방향으로 만든 `명단·설정` 시안.

세 이미지는 2026-09-09 Codex Product Design 탐색 결과이며 이 작업의 시각 비교 기준이다.
화면의 가상 학생 이름과 그림은 레이아웃 설명용이다. 제품에는 교사 소유 학급 API가 반환하는
실제 명단, 작품 썸네일, 완성 그림책 표지만 표시한다.

구현에서 의도적으로 유지한 제품 차이:

- 학급에 회차가 열려 있으면 오늘 수업에는 그 회차와 일치하는 그림만 보인다.
- 학생 이름은 교사 화면에서만 사용하고 학생·가족·AI 응답으로 내보내지 않는다.
- 학생 삭제는 복원 가능하지만 학급 삭제와 수업 코드 변경은 결과를 먼저 설명한다.
- 완성 그림책의 자세히 보기와 PDF 저장은 기존 전용 화면으로 연결한다.
