한눈에 비교

번호 이름 핵심 색 아이 화면 인상 교사 화면을 어른스럽게 만드는 장치 위험
1번라벤더 크레용 #F8F4EE · #6E4FC9 · #E8613C · #F5CE4A 가장 장난스럽고 밝다. 보라라서 성별 기울기가 없다. 같은 보라를 #4B3A8C로 깊게, 라운드 24→8px, 코랄·옐로 제거 보라를 분홍 계열로 읽는 어른이 간혹 있음
2번숲 그늘 교실 #FBF7EC · #2F6E62 · #E09A2E 차분하고 안정적. 오래 보는 화면에 가장 무난. 틸을 #22544B로, 표 형태 + 라벨 자간 확대, 앰버는 뱃지만 1~3학년에겐 다소 어른스러울 수 있음
3번모래와 이끼 #F7F2E5 · #5A7040 · #DE9450 따뜻한 자연색. 아이 그림 색을 가장 잘 받아 준다. 올리브 #3F5230 + 무채 라벨, 도형·별 장식 제거 올리브가 화면에 따라 탁해 보일 수 있음
4번먹과 한지 #F5F2EC · #2B3140 · #C9971C 가장 조용함. 그림이 유일한 색이 된다. 손댈 게 거의 없다 — 그대로가 이미 어른 톤 아이 화면이 심심할 위험이 가장 큼
5번굵은 사인펜 #FBF6EA · #1A1A1A · #0E9C93 · #F5CE4A 씩씩하고 또렷. 선택 상태가 색 없이 굵기로 읽힌다. 테두리 3px→1px, 검정 버튼 대신 터콰이즈 #0B6F69 검정 면적이 커지면 딱딱해짐

다섯 안이 공통으로 지킨 것

빨강·초록 의미색 금지어느 안에도 “맞음 초록 / 틀림 빨강” 짝이 없다. 3번의 초록은 흙빛 올리브라 단독으로 쓰이고, 빨강 계열은 1번 코랄뿐인데 이는 ‘오늘’ 표시용 강조지 오류색이 아니다.
아직 안 그린 쪽모두 배경 크림보다 한 톤 낮은 중립색 + 점선 + ＋ 기호. 노랑·빨강 경고 톤을 쓰지 않아 “빠뜨렸다”가 아니라 “여기 아직 비어 있어”로 읽힌다.
색만으로 상태 표시 안 함그린 쪽은 테두리가 진해지고 캡션 앞에 ✓가 붙는다. 오늘 회차는 뱃지 글자(‘오늘 그릴 쪽’)로도 말한다.
흰 도화지가 주인공배경을 순백이 아닌 크림으로 두어 흰 종이가 항상 배경보다 밝다. 채도 높은 색은 버튼·뱃지처럼 작은 면적에만 쓴다.
본문 대비본문·보조 글자 모두 각자의 배경에서 WCAG AA(4.5:1) 이상, 주요 버튼의 흰 글씨도 AA 이상이 되도록 원본 레퍼런스 색을 눌러 잡았다(예: 라벤더 #B69CE8 → #6E4FC9).
