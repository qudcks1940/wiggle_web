# 몽그리 표정 사용 제안

2026-09-09. 사용자는 그리기에서 실제로 몽그리가 쓰이는 곳을 확인한 뒤 필요한 표정을 제안하고 만들어 달라고 요청했다. 이 문서는 코드 조사와 표정 탐색안이며 확정 제품 결정이나 구현 완료 기록이 아니다.

## 현재 코드에서 확인한 흐름

- `app/components/DrawingStudio.tsx`의 `askGrimi`: 아이가 ‘몽그리 부르기’를 누르면 패널을 열고 현재 그림을 저장한 뒤 코칭 요청을 보낸다.
- `grimiLoading`: 점 세 개와 ‘그림을 보고 있어요…’를 표시한다. 현재 이 상태값은 코칭 생성 외에 답변 기록·가이드 요청에도 공유된다.
- `coaching`: 질문 하나와 선택지, 직접 답변 입력을 보여 준다. 답변이 있으면 `nextAction`과 기록 버튼을 보여 준다.
- `grimiCollapsed`: ‘그리러 가기’를 누르면 다음에 그릴 일과 기록 버튼만 남긴다.
- `aiGuide`: 요청한 주제의 단계별 안내와 선택지·이전/다음 버튼을 보여 준다.
- `answerSaved`: ‘과정에 남겼어요’를 표시한다. 새 그림을 평가하거나 새 관찰 문장을 생성한 결과가 아니다.
- `grimiError`: 오류 문장을 표시한다.
- 현재 패널 제목은 반짝임 기호, 호출 버튼은 SparklesIcon이다. 이 영역에 오리 표정 이미지가 연결되어 있지 않다.

## 제안 표정 6종

| 표정 / 파일명 제안 | 쓰임 | 표정과 몸짓 | 문구 예시(새 제안) |
|---|---|---|---|
| 궁금함 / curious | 질문과 선택지, 대상을 확신하지 못한 경우 | 고개 갸웃, 한쪽 눈썹 상승, 살짝 열린 부리 | 이 친구는 어디로 가고 있을까? |
| 생각 중 / thinking | 그림 분석 또는 가이드 생성 대기 | 시선 위쪽, 턱에 손, 편안한 눈썹 | 그림을 보고 있어요… |
| 제안 / suggesting | nextAction 또는 가이드 단계 | 부드러운 미소, 손바닥을 열어 권유 | 여기에 길을 하나 이어 보면 어때? |
| 발견의 놀람 / delighted | 확인된 그림 요소에 대한 관찰을 표현할 때 | 커진 눈과 둥근 부리, 가볍게 올라간 손 | 오? 여기에 작은 별도 있네! |
| 경청 / listening | 답변을 고르거나 적는 동안, 접힌 패널 기본 모습 | 편안한 눈과 작은 미소, 약간 앞으로 기울임 | 네 이야기가 궁금해. |
| 안심 / reassuring | 연결 오류, 잠시 응답이 어려운 경우 | 부드러운 눈썹, 가슴에 손, 작은 미소 | 잠깐 연결이 끊겼어. 다시 불러 줄래? |

위 문구는 확정 음성이나 제품 문자열을 교체한 것이 아니다. 구체적인 별·길 등은 실제 그림에서 확인되거나 아이가 선택했을 때만 사용한다. 기술 오류가 아닌 상황에서 연결이 끊겼다고 말하지 않는다.

## 평가 표현과 발견 표현

사용자 예시 ‘오? 이 그림 정말 대단한데?’의 감탄하는 표정은 만들 수 있다. 다만 현재 `docs/product-decisions.md`와 `lib/openai-coaching.ts`는 AI가 아이의 그림을 평가하거나 칭찬 판정하지 않는 방향이며 ‘대단’도 필터 대상이다. 현재 방향을 유지한다면 기쁨·놀람을 ‘새로운 것을 발견한 표정’으로 쓰고, 문장은 구체적인 관찰과 호기심으로 구성한다. 이 작업에서는 정책·프롬프트·필터를 바꾸지 않았다.

발견 표정은 현재 UI에 별도 연결 지점이 없다. `observedElements`는 응답 데이터에 있으나 이 패널에서 관찰 문구로 직접 렌더링하지 않는다. 처음에는 궁금함·생각 중·제안·경청·안심을 상태에 연결하고 발견 표정은 후속 확장용으로 두는 것을 권장한다. 저장 성공을 그림에 대한 감탄으로 매핑하지 않는다.

## 그림 안에서 쓰는 방법

- 패널의 표정은 기본 80~112px, 접힌 안내에서는 32~40px 정도를 시작값으로 잡는다. 실제 반응형 크기는 구현 후 검증한다.
- 말풍선 옆에 오리 하나만 둔다. 그림을 가리는 큰 팝업이나 자동 감탄을 추가하지 않는다. 아이가 도움을 요청하는 기존 흐름을 유지한다.
- 표정 선택은 UI 상태로 결정한다. AI 자유 텍스트에서 ‘대단’, ‘오’ 같은 단어를 검색해 감정을 추측하지 않는다.
- 우선순위 예시: 오류 → 처리 중 → 다음 행동 제안 → 답변 경청 → 질문. 처리 중은 요청 종류를 구분해 ‘그림을 보는 중’과 ‘과정을 기록하는 중’ 문구가 맞도록 한다.
- 파란 베레모·스카프, 노란 오리 얼굴 비율, 눈·부리, 이미지 크기와 기준선을 일관되게 맞춘다.
- 화남·실망·한숨·비교하는 표정은 이번 세트에 넣지 않았다. 기술 오류도 아이에게 실망하는 표정으로 보이지 않게 한다.
- 표정 시트는 검토용이며 앱용 스프라이트가 아니다. 개별 투명 에셋은 표정 선택·수정 뒤 별도로 제작한다. 지금 시트는 불투명 배경이다.

## 제작

내장 ImageGen 사용. 참조는 `docs/design-assets/number-keypad/assets/mongri-keypad-ivory.png`. 같은 오리의 얼굴과 상반신 6개를 한 시트로 제작했다. 프롬프트는 `prompt.txt`에 보관한다. 앱 코드는 수정하지 않았다. 브라우저 실측이 아닌 소스 코드 기준 조사다.
