# 친구 고르기 화면 그림 요청서 (코덱스용)

> 작성: 2026-09-14 · 시안: `docs/design-assets/animal-picker/mockup-2026-09-13.png` (1689×931)
> 화면 코드는 이미 시안 배치로 만들어져 있고, 지금은 옛 2D 동물 그림을 임시로 쓴다.
> 아래 파일을 **같은 이름으로** 넣으면 코드 수정 없이 바뀐다(동물 그림). 장식 그림은 넣을 자리를 코드에 추가해야 한다.

## 공통 규격

- **투명 배경 PNG**(알파 채널). 흰 배경·크림 배경을 깔지 않는다 — 화면 배경은 `#fdf8e6`이지만 카드 면은 `#fefdf5`, 선택 카드는 `#f4f8e7`라 배경을 구우면 경계가 보인다.
- **스타일**: 시안과 같은 폭신한 펠트 인형 3D. 몽그리(`public/landing-gallery/duck-painter-640.webp`)와 같은 질감·조명.
- **해상도**: 태블릿 레티나에서 선명하도록 아래 픽셀 크기 이상. 우리가 webp로 줄여 쓴다.
- 그림 안에 **글자를 넣지 않는다**(아래 손글씨 한 장만 예외). 이름·반 이름은 화면에서 HTML로 쓴다.

## 1. 동물 친구 10종 — 필수

| 파일 이름 | 동물 | 화면 이름 |
|---|---|---|
| `rabbit.png` | 토끼 | 솔이 |
| `bear.png` | 곰 | 보리 |
| `fox.png` | 여우 | 루루 |
| `tiger.png` | 호랑이 | 호두 |
| `panda.png` | 판다 | 모모 |
| `dog.png` | 강아지 | 두부 |
| `cat.png` | 고양이 | 나비 |
| `koala.png` | 코알라 | 코코 |
| `lion.png` | 사자 | 해솔 |
| `frog.png` | 개구리 | 초롱 |

- **크기**: 1024×1024 정사각형.
- **구도**: 정면을 보는 상반신. 두 앞발이 그림 **아래 가장자리에 걸치게** 둔다(시안처럼 이름 띠 위로 고개와 앞발이 올라온 모양).
- **여백**: 좌우 가운데 정렬, 아래는 여백 없이 가장자리까지, 위·옆은 10% 이내. 귀가 긴 토끼도 캔버스 안에 들어와야 한다.
- 열 마리의 **머리 크기와 눈높이를 맞춘다** — 격자에 나란히 놓이므로 한 마리만 크면 튄다.
- 넣을 곳: `public/entry-green/animals/<같은 이름>.webp` (우리가 PNG→webp 변환).

## 2. 이름 띠 — 필수

- 시안의 연두색 붓 자국. 한 장만 만들어 모든 이름에 쓴다.
- **크기**: 600×180, 투명 배경. 색은 `#dbf1ba` 근처, 가장자리가 붓처럼 거친 가로 띠.
- 이름은 두세 글자라 가로로 늘릴 필요는 없다.

| 파일 이름 | 내용 | 크기 |

## 4. 반 이름 간판 — 권장

- 시안 오른쪽 위의 나무 간판 + 새싹. 반 이름 글자는 우리가 HTML로 얹는다.
- 반 이름 길이가 달라지므로 **세 조각**으로 요청: `sign-left.png`(왼쪽 끝+못), `sign-middle.png`(가로로 이어 붙일 나무판), `sign-right.png`(오른쪽 끝+못). 새싹은 `sign-sprout.png` 따로.
- 높이 220px 기준, 투명 배경.

## 코덱스에 그대로 붙여 넣을 요청 문장

> 첨부한 시안(mockup-2026-09-13.png)의 친구 고르기 화면에 쓸 그림을 만들어 줘. 모두 투명 배경 PNG, 폭신한 펠트 인형 3D 스타일로 첨부한 몽그리와 같은 질감이야. 먼저 동물 10종(토끼·곰·여우·호랑이·판다·강아지·고양이·코알라·사자·개구리)을 1024×1024로, 정면 상반신에 두 앞발이 그림 아래 가장자리에 걸치게, 좌우 가운데·아래 여백 없이, 열 마리의 머리 크기와 눈높이를 맞춰서. 파일 이름은 rabbit·bear·fox·tiger·panda·dog·cat·koala·lion·frog.png. 그다음 연두색 붓 자국 이름 띠 600×180 한 장. 글자는 그림에 넣지 마.
