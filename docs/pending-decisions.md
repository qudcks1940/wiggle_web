## P-001 학생을 실제로 구분하는 운영 방식 — 2026-09-07 확정, `product-decisions.md`로 이동

교사가 학급을 만들 때 명단(번호 + 실명)을 직접 입력하고, 학생은 수업 코드나 QR로 들어와
자기 번호와 그림 비밀번호로 자기 창을 연다. 명단은 학생 화면에 보여 주지 않는다.
확정 내용과 이유는 `product-decisions.md`의 `학생 입장과 기록` 7번에 있다.

## P-003 교사 확인 화면 이후의 운영 범위

2026-08-18 읽기 전용 1차 화면에 다음 정보가 구현됐다.

- 동물과 별명
- 프로필 생성 시각과 마지막 활동 시각
- 진행 중·완료 작품 수
- 현재 진행 상태와 최근 작품
- 같은 학급 안의 중복 별명 표시

번호·실명 명단은 2026-09-07에 확정돼 P-001에서 옮겨 갔다(`product-decisions.md`). 아직 결정하지 않은 것은 교사 메모와 외부 명부(NEIS 등) 연결이며, 그 입력란은 운영 방식이 정해지기 전에는 추가하지 않는다.

## P-004 그림책 피드백 실행 정책 — 루브릭·PDF 요구 2026-09-09 확정

사용자가 XLSX 10개 평가 영역과 서술형 PDF 예시, 교체 가능한 파일·프롬프트, 개별/일괄 실행을 제공했다. 기존 루브릭 미제공 대기는 해소됐다. 상세 확정 원문은 product-decisions.md 참조.

현재 구현은 한 권씩 처리·실패 재시도, 교사 전용 AI 초안/PDF다. 다음 질문은 아직 사용자 결정이 없다: “교사가 AI 초안을 검토·수정·승인한 뒤 학생에게 보여 줄지, 교사용으로만 둘지”. 학생 자동 공개와 앱 안 초안 편집·승인 기능은 이번에 추가하지 않았다.

실물 운영은 키 발급 후 Sandbox 검증, 사용자 배포 후 운영 실측, 대표 1부 교정이 남아 있다. 첫/마지막 쪽의 표지 재사용과 최소 쪽까지 빈 쪽 추가는 현재 구현 선택이며 화면과 운영 안내에 표시한다.

## 갱신 규칙

1. 사용자가 항목을 확정하면 결정 내용과 이유를 `product-decisions.md`로 옮긴다.
2. 구현만 끝났다고 제품 결정이 확정된 것으로 보지 않는다.
3. 질문 번호만 기록하지 말고 질문 문장과 선택 결과를 함께 남긴다.
4. 최근 대화와 문서가 충돌하면 사용자의 가장 최근 명시적 지시를 우선하고 문서를 즉시 수정한다.
