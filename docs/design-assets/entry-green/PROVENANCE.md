# 제작 이력

2026-09-07, Codex 내장 ImageGen으로 생성/편집했다. 외부 이미지 API는 사용하지 않았다.

1. 선택된 초록색 교실 시안에서 팔레트 쪽 날개를 내려 팔레트 구멍/가장자리를 잡도록 국소 수정했다. 나머지 구도와 초록 환경, 파란 모자·스카프는 보존하도록 요청했다.
2. 수정 시안에서 오리와 UI·문구·간판 글자를 제거하고 가려진 문과 바닥을 복원해 빈 교실 배경을 만들었다.
3. 수정 시안에서 UI·문구·간판 글자만 제거하고 팔레트를 잡는 오리와 방을 유지해 완성 장면을 만들었다.
4. 수정한 자세를 투명 이미지로 분리하는 두 시도는 실제 알파가 없는 RGB 체크무늬 결과여서 전달 묶음에서 제외했다.
5. 독립 오리는 `public/landing-gallery/duck-painter.png`를 그대로 재사용했다. 이 파일의 이전 생성 출처는 저장소 `public/landing-gallery/manifest.json` 참조.
6. 배포용 WebP 인코딩과 640px 축소에는 sharp를 사용했다. 원본 PNG도 함께 보존했다.

각 파일의 원본 경로와 SHA-256은 manifest.json에 있다. generated_images 경로는 출처 기록일 뿐, 구현 시 그 경로를 참조하지 말고 전달 폴더의 assets 파일을 복사해 사용한다.
