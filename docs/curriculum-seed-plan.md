# 씨앗 선 커리큘럼 계획 (12회 기본)

> 마지막 갱신: 2026-09-09
> 상태: 사용자와 대화로 뼈대를 확정한 **계획 문서**. 코드 반영 전이다. 기존 30개 레슨(`lib/lesson-content.ts`)은 이 계획의 기준이 아니며, 이 계획이 구현되면 대체된다.

## 확정한 뼈대 (2026-09-09 사용자 결정)

1. 회차는 **12회 기본**. 학교는 한 학기 12회, 학원·지역아동센터는 같은 형식으로 12회를 더 붙여 확장한다.
2. **앞 회차는 주제를 주고 뒤로 갈수록 연다.** 1~4회는 주제가 있고 5회부터 열어둔다.
3. **반 친구 그림을 보여 주고 교실에서 말로 토론한다.** 앱은 그림만 크게 띄운다. 앱 안 댓글·스티커·투표는 만들지 않는다.
4. 성장 축은 Torrance 창의성 검사의 네 축을 그대로 쓴다: **많이 떠올리기 → 다르게 보기 → 남과 다르게 → 더 자세히**.
5. 한 회차의 리듬은 항상 같다: **씨앗 받기 → 변신시키기 → 이야기 한 줄 → 친구 그림 보기**.

## 용어

- **씨앗 선**: 도화지에 미리 그어진 보통의 획. 지울 수 있고 저장 이미지에 남는다. 정답 점선(`guide`)이 아니다.
- **Torrance**: 창의성 검사(TTCT). 미완성 도형 완성 과제와 네 채점 축의 출처. 씨앗 선 형식과 성장 축이 여기서 왔다.
- **감상·토론**: 반 친구 그림을 보고 말하는 활동. Torrance가 아니라 미술과 감상 영역에 해당한다. 대화 틀은 우리가 직접 쓴 문장만 쓴다(Project Zero 자료는 CC BY-NC-ND라 번역·상업 이용 금지 — `product-decisions.md` 5번).

## 세 고객이 원하는 것

- 아이: 5분 안에 무언가가 되고, 옆 친구와 다르고, 자랑할 수 있어야 한다.
- 학교: 40분에 끝나고 준비물이 없고 성취기준에 붙고 반 전체 결과물이 한눈에 보여야 한다. "같은 씨앗, 서른 개의 다른 그림"을 벽에 붙이는 장면이 목표다.
- 학원·지역아동센터: 어른이 붙어 있지 않아도 혼자 진행되고 매번 결과물이 나오고 성장 기록이 쌓여야 한다.

## 한 회차 40분

| 시간 | 활동 | 앱 |
|---|---|---|
| 5분 | 씨앗 받기 — 음성 안내 한 문장, 씨앗이 그어진 도화지 | 씨앗을 `pencil` 획으로 심어 둔 새 작품 |
| 20분 | 변신시키기 — 안내 문장 3개를 차례로, 각각 씨앗 하나 | 기존 그리기 화면 |
| 5분 | 이야기 한 줄 | 기존 소감·짧은 글 |
| 10분 | 친구 그림 보기 + 말로 토론 | **반 작품 크게 보기** (아래 "앱에 필요한 것") |

## 씨앗 설계 규칙

- 씨앗 하나로 **최소 세 가지** 다른 것이 될 수 있어야 한다. 안 되면 정답 점선과 같아진다.
- 씨앗은 도화지 한 부분만 차지하고 여백을 남긴다.
- 씨앗이 여럿이면 서로 멀리 두어 각각 독립된 그림이 되게 한다.
- 안내 문장은 지시("~하세요")가 아니라 질문("뭘 만들까?")이다. 한 문장 20자 안팎, 음성으로 읽힌다.
- 좌표는 도화지 정규화 좌표(0~1, 가로 4:3 기준). 원·반원·나선은 폴리라인으로 생성한다.

## 12회 표

축 약어: 많이 = 많이 떠올리기, 다르게 = 다르게 보기, 남과 = 남과 다르게, 자세히 = 더 자세히.

| 회차 | 축 | 씨앗 | 주제 | 될 수 있는 것(예시 3) |
|---|---|---|---|---|
| 1 | 많이 | 세로 직선 하나 `[[.5,.25],[.5,.62]]` | 동물 | 기린 목, 뱀, 새 다리 |
| 2 | 많이 | 곡선 하나 `[[.3,.55],[.4,.42],[.5,.5],[.6,.6],[.7,.48]]` | 먹는 것 | 국수, 바나나, 소시지 |
| 3 | 많이 | 동그라미 하나 (중심 `.5,.5` 반지름 `.12`) | 우리 집 물건 | 시계, 접시, 단추 |
| 4 | 다르게 | 꺾은선 `[[.3,.6],[.42,.4],[.54,.6],[.66,.4]]` | 밖에서 본 것 | 산, 번개, 악어 입 |
| 5 | 다르게 | 반원 (중심 `.5,.55` 반지름 `.15`, 위쪽) | 열어둠 | 우산, 거북, 무지개 |
| 6 | 다르게 | 교차하는 선 두 개 `[[.35,.35],[.65,.65]]`, `[[.65,.35],[.35,.65]]` | 열어둠 | 풍차, 나비, 가위 |
| 7 | 남과 | 귀 두 개 모양 `[[.42,.42],[.45,.28],[.5,.42]]`, `[[.5,.42],[.55,.28],[.58,.42]]` | 열어둠 | 고양이, 왕관, 산 두 개 |
| 8 | 남과 | 바퀴 하나(중심 `.4,.65` 반지름 `.08`)와 선 `[[.48,.65],[.75,.65]]` | 열어둠 | 외발 자전거, 수레, 청소기 |
| 9 | 남과 | 세 씨앗 조합: 세로선 `[[.25,.3],[.25,.55]]`, 곡선 `[[.45,.6],[.55,.5],[.65,.6]]`, 작은 원(중심 `.75,.3` 반지름 `.05`) | 열어둠 | 한 장면으로 잇기 |
| 10 | 자세히 | 사진에서 뽑은 특징 선 — 달팽이 나선 2바퀴(중심 `.5,.5`, 사진 `snail-closeup`) | 열어둠 | 달팽이, 소용돌이, 롤케이크 |
| 11 | 자세히 | 1~9회 씨앗 중 내가 고른 것 | 열어둠 | 배경·색·이야기까지 완성 |
| 12 | 전시 | 반 전체 같은 씨앗: 물결 `[[.2,.6],[.35,.45],[.5,.6],[.65,.45],[.8,.6]]` | 열어둠 | 벽에 붙이는 반 전시 |

### 회차별 안내 문장(4개)과 토론 질문(3개)

형식: 안내 1~3은 씨앗 하나씩, 안내 4는 자유. 토론 질문은 교사가 교실에서 말로 쓴다. 앱에는 넣지 않고 교사 화면의 회차 카드에만 보여 준다.

**1회 · 세로 직선 · 동물**
- 안내: 선이 하나 있어. 어떤 동물이 될까? / 같은 선이 다른 동물도 될 수 있을까? / 하나 더, 아까와 다른 동물로 만들어 봐. / 내 동물에게 이름과 이야기를 붙여 줘.
- 토론: 같은 선인데 뭐가 됐어? / 제일 뜻밖인 동물은 누구야? / 그 친구는 선을 어디로 봤을까?

**2회 · 곡선 · 먹는 것**
- 안내: 구불구불한 선이야. 무슨 음식이 될까? / 뒤집어 보면 다른 음식도 보여? / 또 하나, 다른 음식으로 만들어 봐. / 누가 먹는지 그려 줘.
- 토론: 뜻밖인 음식은 뭐야? / 선을 뒤집은 친구 있어? / 왜 그렇게 봤는지 물어보자.

**3회 · 동그라미 · 우리 집 물건**
- 안내: 동그라미가 있어. 우리 집 어디에 있을까? / 다른 방에도 동그라미가 있을까? / 하나 더, 아주 작은 것으로 만들어 봐. / 그 물건이 있는 방을 그려 줘.
- 토론: 동그라미가 어디에 숨었어? / 같은 물건을 만든 친구가 있어? / 아무도 안 만든 물건은 뭐야?

**4회 · 꺾은선 · 밖에서 본 것**
- 안내: 뾰족뾰족한 선이야. 밖에서 본 것 중 뭐가 될까? / 도화지를 돌려서 봐. 다른 게 보여? / 또 돌려서 하나 더. / 그 장소에 나를 그려 줘.
- 토론: 도화지를 돌리면 뭐로 보여? / 위로 본 친구와 옆으로 본 친구가 어떻게 달라? / 셋 다 다른 친구 있어?

**5회 · 반원 · 열어둠**
- 안내: 반원이 있어. 뭐가 될까? / 뒤집으면 뭐가 될까? / 반원을 두 개로 나누면? / 내 그림에 날씨를 더해 줘.
- 토론: 뒤집으면 달라지는 게 뭐야? / 반원을 잘라 쓴 친구 있어? / 제일 큰 것과 제일 작은 것을 찾아보자.

**6회 · 교차하는 선 두 개 · 열어둠**
- 안내: 선 두 개가 만났어. 뭐가 될까? / 만난 자리를 가운데가 아니라 끝으로 보면? / 하나 더, 움직이는 것으로. / 어디로 가는지 그려 줘.
- 토론: 친구는 어디를 앞으로 봤어? / 움직이는 것으로 만든 친구는 뭘 만들었어? / 두 선을 따로 쓴 친구 있어?

**7회 · 귀 두 개 모양 · 열어둠** (친구 그림을 먼저 보고 시작)
- 안내: 귀처럼 보이지? 귀가 아닌 것으로도 만들어 봐. / 친구들 그림을 봤지? 아무도 안 만든 것으로. / 하나 더, 사람이 아닌 것으로. / 그것이 사는 곳을 그려 줘.
- 토론: 아무도 안 만든 건 뭐야? / 귀로 본 친구와 아닌 친구가 몇 명이야? / 어떻게 그 생각이 났어?

**8회 · 바퀴 하나와 선 · 열어둠**
- 안내: 바퀴 하나와 선이 있어. 뭐가 될까? / 바퀴가 아닌 것으로 보면? / 친구들 그림에 없는 것으로 하나 더. / 누가 타는지 그려 줘.
- 토론: 왜 그렇게 봤는지 물어보자. / 바퀴를 바퀴로 안 쓴 친구 있어? / 제일 빠른 것과 제일 느린 것은?

**9회 · 세 씨앗 조합 · 열어둠**
- 안내: 씨앗이 셋이야. 하나씩 무언가로 만들어 봐. / 셋을 한 장면으로 이을 수 있을까? / 친구들과 다른 이야기로. / 제목을 붙여 줘.
- 토론: 셋을 하나로 이은 친구 있어? / 따로따로 만든 친구 그림은 뭐가 좋아? / 제목만 듣고 그림을 맞혀 보자.

**10회 · 사진 특징 선(달팽이 나선) · 열어둠**
- 안내: 사진을 봐. 이 선이 사진 어디에 있어? / 사진에 없는 것을 더해 봐. / 나선을 달팽이가 아닌 것으로 하나 더. / 배경까지 채워 줘.
- 토론: 사진에 없는 걸 뭘 더했어? / 사진과 제일 다른 그림은 누구 거야? / 나선이 달팽이가 아닌 친구 있어?

**11회 · 내가 고른 씨앗 · 열어둠**
- 안내: 지금까지 씨앗 중 하나를 골라. / 그때 못 만든 것으로 만들어 봐. / 색을 세 가지 이상 써 봐. / 이야기를 두 줄로 써 줘.
- 토론: 처음과 뭐가 달라졌어? / 왜 그 씨앗을 골랐어? / 색이 이야기와 어울려?

**12회 · 반 전체 같은 씨앗(물결) · 전시**
- 안내: 우리 반 모두 같은 선이야. 뭐가 될까? / 친구와 다르게 만들어 봐. / 완성해 줘. 벽에 붙일 거야. / 제목과 이름표를 써 줘.
- 토론: 우리 반 그림을 한꺼번에 보면 뭐가 보여? / 같은 선이 몇 가지가 됐어? / 다음 씨앗은 뭐로 할까?

## 앱에 필요한 것 (구현 시)

1. `Lesson.seed` (정규화 좌표 폴리라인 배열) — `claude/seed-line-lesson` 브랜치에 형식이 있다. 작품 생성 시 `pencil` 획으로 심고 `guide`는 비운다.
2. **반 작품 크게 보기**: 교사가 회차를 열면 그 회차의 반 작품을 격자로 보여 주고, 하나를 누르면 화면 가득 크게 띄운다. 이름·번호 없이 그림만. 교사 화면(칠판·TV 연결)이 기본이고, 학생 화면에서는 교사가 연 동안만 볼 수 있다. 댓글·좋아요·투표 없음.
3. 교사 회차 카드에 토론 질문 3개와 40분 배분을 표시한다. 학생 화면에는 안내 문장만 나간다.
4. 11회는 씨앗 선택 화면이 필요하다(1~9회 씨앗 그림 9개 중 고르기).
5. 10회는 기존 관찰 사진(`public/lessons/observe/snail-closeup.webp`)을 재사용한다.
