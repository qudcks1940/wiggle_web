# 위글(Wiggle Web) — 경험 스파인

> 이 문서는 **행동(behavior)의 정본**이다. 모습(look)의 정본은 같은 폴더의 `DESIGN.md`이며, 이 문서는 시각 값을 절대 다시 적지 않고 `{colors.…}` 형태의 토큰 이름으로만 가리킨다. 두 문서는 목업·와이어프레임·import보다 우선한다(product-decisions.md 「폐기된 결정 — 재설계 금지 조항」의 대체 조항).

## Foundation

- **폼팩터**: 공용 교실 태블릿의 브라우저가 기준이며 **가로 화면이 기본**이다. 휴대전화 세로도 대응한다. 최소 검증 뷰포트는 `320×568` / `390×844` / `844×390`(NFR-2).
- **UI 시스템 없음.** 컴포넌트 라이브러리를 쓰지 않는 자체 CSS다. 따라서 모든 컴포넌트의 행동 규칙은 이 문서가, 시각 사양은 `DESIGN.md`가 각각 유일한 정본이다.
- **공용 기기 전제**: 한 태블릿을 여러 아이가 돌려 쓴다. 학생 전환 시 기존 세션 해지, 최근 학생 목록 비노출(FR-29). 어떤 화면도 "이 기기의 주인"을 가정하지 않는다.
- **교사 부재 전제**: 교사가 태블릿 앞에 없어도 수업이 굴러간다(FR-33). 학생 흐름 어디에도 교사 조작을 기다리며 멈추는 지점을 두지 않는다(AD-14 — 기본값은 교실).
- **입력**: 스타일러스 펜이 기본, 손가락 그리기는 명시적 선택(캔버스 결정 1·2).

## Voice and Tone

### 아이 쪽
- **한국어 존댓말**이되 짧고 쉽다. 서버 오류 메시지도 아이가 읽는 존댓말이다(AD-7).
- 태블릿 크기에서는 한 화면 입력, 짧은 세로 화면에서는 3단계 안내형(학생UI-6).
- **음성 안내는 페이지당 정확히 1개**, 페이지 상단에 둔다. 그 페이지에서 해야 할 일을 처음부터 짧게 안내한다. 항목별 개별 음성 버튼 금지. **자동 재생 금지.** 문장은 제품에 확정된 시나리오 문장을 그대로 읽는다 — **AI가 만들거나 바꾸지 않는다**(FR-22, 학생UI-7).

**금지 어휘 목록(아이 화면 전체):**

| 금지 | 대신 |
|---|---|
| 잘했어요 / 참 잘했어요 (판정 칭찬) | 사실 서술: "그림이 3쪽에 들어갔어요" |
| 틀렸어요 / 실패 / 오답 | (개념 자체가 없다) |
| 점수 / 순위 / 등수 / 몇 등 | (개념 자체가 없다) |
| 아직 못 한 / 밀린 / 미완료 / 빠뜨린 | **"아직 안 그린 쪽"** |
| 서둘러요 / 시간이 없어요 (재촉) | (재촉하지 않는다) |

### 교사 쪽
사무적이되 차갑지 않게. 개수와 동사 중심, 이모지·낙서·감탄사 없음(DESIGN.md 교사 레지스터). 단 하나의 예외적 무게: **학급 삭제 문구는 되돌릴 수 없다는 것과 아이가 그림을 다시 열 수 없다는 것을 숨기지 않는다**(AD-17). 반대로 **아크 전환·종료 문구는 "되돌릴 수 있어요" 톤이다**(FR-2a, Story 3.3).

### 그리미 발화 규칙
- 질문은 **한 번에 정확히 하나**. 답 칩은 정답 없는 2~4개(FR-18).
- 모르면 추측을 단정하지 않는다. `틀리는 해석자`의 추측은 **항상 물음표로 끝나는 열린 추측**이다: "어? 난 이게 우산처럼 보이는데?" — "이건 우산이네요"라고 단정하지 않는다.
- 대신 그려주기·평가·재능 진단·실패 표현 금지. 서버의 `isChildSafeCoachingText`가 최종 관문(FR-17).

## Component Patterns

행동 규칙만 적는다. 시각 사양은 `DESIGN.md`의 해당 컴포넌트 절 참조.

| 컴포넌트 | 시각 정본 | 행동 규칙 |
|---|---|---|
| 오늘 회차 카드 | {components.episode-card} | 최소 형상: **장면 삽화 + 회차 제목 + 장면 문장 한 줄 + 큰 시작 버튼**({spacing.touch-hero}, Story 2.2 확정). 학급 포인터를 **12초 주기 폴링**으로 확인 — 교사가 회차를 바꾸면 다음 폴링에 카드가 갱신된다. **그리던 그림은 절대 강제 전환·소실되지 않는다**(FR-33, Story 2.2 AC). 이미 그 회차를 그린 아이에게는 이어 열기/다시 열기를 제안한다 |
| 지난 그림 서랍 | 시각·애니메이션 사양은 DESIGN.md 소관(현재 미정) | 그리기 화면 **도구 마대 옆 버튼**으로 연다 → 지난 회차 그림이 옆에서 미끄러져 나온다 → **보면서 그릴 수 있다** → 닫으면 도화지가 전체 복귀(FR-6 확정). **보기 전용** — 그 위에 그리는 캔버스가 아니다(Story 3.1). 같은 아크의 이전 회차 작품만, `artworks` 귀속으로 조회(책을 거치지 않는다). 로딩 중엔 자리 표시, 지난 그림이 없으면 "아직 지난 그림이 없어요" 류의 차분한 문구 — 결손 표현 금지 |
| 그리미 호출 버튼 + 말풍선 | {components.grimi-bubble} | 그리미는 **아이가 버튼을 눌렀을 때만** 말한다(FR-16). 완료 후에도 **자동 등장 금지** — 모드만 `틀리는 해석자`로 바뀌고 등장은 여전히 호출이다(AD-16). 모드 전환의 유일한 신호는 아이의 완료 행동이며 시간·휴리스틱·모델 판단으로 바뀌지 않는다 |
| 동화책 쪽 띠 | {components.storybook-page-strip} | 응답의 `artworkId: null`인 쪽을 `아직 안 그린 쪽`으로 보여준다(AD-15). 빈 쪽 탭은 **이번 범위에서 반응 없음** [ASSUMPTION — 집에서 채우기(FR-10) 보류에 딸린 결정]. 쪽 순서는 아크 상수가 정본(AD-11). 빈 쪽 개수·비율을 세거나 표시하지 않는다 |
| 수업 조종석 | 교사 레지스터({components.button-teacher}) | 학급 화면 **맨 위**. 아크 이름 · 현재 회차 · **다음 회차 열기**를 한 곳에(FR-34 확정, Story 2.1 컨트롤 재사용). 다음 회차 열기는 **확인 없이 즉시 실행** — 되돌릴 수 있는 정상 동작이므로(FR-2a). 실행 취소 UI는 두지 않는다(같은 컨트롤로 이전 회차를 다시 지정하면 된다). 아크 전환·종료에는 확인 한 번 + "되돌릴 수 있어요" 톤(Story 3.3). 일주일 뒤 돌아온 교사가 현재 상태를 컨트롤이 아닌 **문장으로** 읽을 수 있어야 한다(Story 2.1 AC) |
| 학생 타일 | 교사 레지스터 | 동물 이모지 + 별명만, **입장 순 고정**. 집계·정렬·진도 표시 없음(AD-15) — 서버가 정렬 키를 주지 않으므로 UI가 만들 수도 없다. 탭 → 학생 상세 |

## State Patterns

> **재입장 실패·중복 프로필**: 기존 학생이 자격정보(동물+별명+그림비밀번호)를 틀리면
> 오류가 아니라 `새로 시작하기` 쪽으로 흘러 **중복 프로필이 생길 수 있다**(자기 동화책과 분리됨).
> 이번 범위에서는 화면으로 막지 않는다 — 교사 화면의 중복 별명 표시(기존 기능)가 유일한 안전망이며,
> **현장 검증 관찰 항목**으로 올린다(비문해 아동의 재입장 성공률, P-001 연계). [ASSUMPTION]

| 상태 | 표면 | 처리 |
|---|---|---|
| 로딩 | 전 표면 | 자리 표시(스켈레톤 류). 빙글 도는 무한 스피너로 아이를 기다리게 하지 않는다 [ASSUMPTION — 구체 형태는 DESIGN.md 소관] |
| 회차 없음(포인터 NULL) | 학생 홈 | **자유 그리기 폴백. 대기 화면 금지**(AD-14 — 기본값은 교실, 교사가 아무것도 안 눌러도 흐름이 막히지 않는다) |
| 빈 상태 | 서랍·보관함·쪽 띠 | "아직 없다"를 차분하게. 결손·미완료·독촉 어휘 금지(Voice 금지 목록) |
| 오프라인 저장 | 그리기 화면 | 저장은 IndexedDB 큐에 보존(FR-12). 아이에게는 "그림은 태블릿에 잘 있어요" 류의 안심 한 줄만 — 경고 배너로 그리기를 방해하지 않는다. 연결 복구 시 큐가 전송된다 |
| 저장 충돌(409) | 그리기 화면 | **자동 재전송 금지**(NFR-3). 아이에게는 그림이 보존돼 있다는 사실 + 명시적 재시도 행동 하나. [ASSUMPTION — 정확한 문구는 확정 시나리오 문장으로 별도 확정] |
| 오류 | 전 표면 | 아이가 읽는 존댓말 + 복구 행동 하나(AD-7). 스택트레이스·내부 정보 노출 금지 |
| 세션 만료(2시간) | 학생 전 표면 | 재입장 유도 — 기존 재입장 수단(`동물 + 별명 + 그림 비밀번호 3개`) 화면으로 안내. 그리던 내용은 로컬 큐가 보존한다. 문구는 만료를 잘못으로 표현하지 않는다 |
| 그리미 응답 실패 | 말풍선 | 그리미가 "지금은 대답을 못 하겠어요" 류로 답하고 그리기는 계속된다. 그리미 없이도 모든 흐름이 완결된다 |

## Interaction Primitives

- **터치 목표 ≥ {spacing.touch-min}**, 아이 일반 행동 {spacing.touch-primary}, 1차 행동 {spacing.touch-hero}(NFR-1).
- **펜 입력 기본 + 팜 리젝션.** 펜 모드에서 손바닥·일반 터치는 그림을 방해하지 않는다. 손가락 그리기는 명시적 선택.
- **두 손가락 = 확대·축소·화면 맞춤.** 한 손가락 제스처와 절대 겹치지 않는다.
- **선택 상태는 3중 표시** — 색 + 형태(테두리·링) + 표지(체크·문구). 색 단독 금지(NFR-1, DESIGN.md 도구 선택·칩 선택 규칙과 일치).
- **자동 저장 신뢰**: 뒤로가기·이탈·전원 꺼짐 어디서든 아이가 저장 버튼을 기억할 필요가 없다. "저장하시겠습니까?" 류의 이탈 확인 대화상자를 두지 않는다.
- 모두 지우기는 확인 후 한 번에, 되돌리기 한 번으로 복원(캔버스 결정 5). 지우개는 지워지는 범위를 네모 커서로(캔버스 결정 6). 굵기는 5단 점 버튼 상시 노출 — 팝업·슬라이더·길게 누르기 금지(캔버스 결정 8).
- **금지**: 시간 제한·카운트다운, 길게 누르기에만 숨긴 기능, 핵심 도구를 가로 스크롤 뒤에 두는 것(NFR-2), 두 겹 모달.

## Accessibility Floor

행동 규칙만. 시각 대비(WCAG AA 비율)는 `DESIGN.md` Colors 절 소관.

- **비문해 완결성**: 핵심 행동(입장, 오늘 회차 시작, 그리기, 완료, 그리미 호출)은 **그림 + 음성 + 큰 터치만으로 완결**된다. 글을 한 글자도 못 읽는 아이가 도움 없이 조작할 수 있어야 한다(NFR-1, 학생UI-3).
- **음성 버튼 규칙**: 페이지 상단 1개, 자동 재생 금지, 한국어 음성 우선, 인위적으로 느리게 만들지 않는다. Web Speech 기기 편차가 있으므로 **텍스트·그림 표지를 항상 병기**한다(NFR-7).
- **스크린 리더**: 모든 인터랙티브 요소에 역할+상태의 한국어 레이블. 크레용 색은 **한국어 색 이름**으로 읽힌다(캔버스 결정 7의 색 이름 표시와 같은 원천).
- 초점 순서는 읽기 순서를 따른다. 선택 상태 3중 표시(위 절)가 색각 이상을 함께 커버한다.

## 그리미 존재 규칙

> **음성 원칙(2026-08-31 확정)**: 그리미 발화는 AI 생성 문장이므로 **음성으로 읽지 않는다** —
> 음성은 확정 시나리오 문장 전용. 비문해 아이의 참여 채널은 ①답 칩의 **이모지**(기존
> `CoachingChoice.emoji` 필드가 이미 존재) ②오늘 장면의 **삽화**다. 그리미 말풍선 텍스트를
> TTS로 보내는 코드를 만들지 않는다.

그리미 캐릭터가 화면에 **언제 있고 언제 없는가**의 정본.

- **그리는 중**: 그리미는 **호출 버튼으로만 존재**한다. 캐릭터·말풍선은 화면에 없다.
- **호출 시**: 말풍선({components.grimi-bubble})과 캐릭터가 등장한다. **도화지 위에 절대 겹치지 않는다** — 도화지({colors.paper})와 그 주변 {spacing.doodle-clearance}는 그리미도 침범 불가.
- **완료 후**: 등장 규칙은 동일하다(호출 시에만). 바뀌는 것은 **모드뿐** — `확장 협업자` → `틀리는 해석자`(AD-16). 전환은 아이의 완료 행동 하나로만 일어난다.
- **닫기**: 아이가 언제든 말풍선을 닫을 수 있고, 닫으면 버튼 상태로 돌아간다. 그리미가 스스로 다시 나타나지 않는다.
- 교사 화면에 그리미는 존재하지 않는다.
- 캐릭터 일관 재현 위험(회차가 바뀌어도 같은 캐릭터, 최소 3표정)은 `DESIGN.md` grimi-bubble 절 참조 — 이 문서는 반복하지 않는다.

## Key Flows

### Flow 1 — 지호(2학년)의 3회차 수업

1. 지호가 태블릿으로 학급 QR을 찍고 `내 그림 이어가기`로 입장한다.
2. 학생 홈을 **오늘 회차 카드**가 차지하고 있다: "3회차 — 친구들과 함께 자전거 타는 장면". 큰 노랑 시작 버튼.
3. 시작 → 그리기 화면. 도화지가 초록 액자 위에 선다.
4. 지난 장면이 기억 안 난다 → 도구 마대 옆 **서랍 버튼** → 1·2회차 그림이 옆에서 미끄러져 나온다. 보면서 자전거 모양을 확인하고, 닫으면 도화지가 전체 복귀.
5. 그린다. 자동 저장이 조용히 돈다.
6. 완료를 누른다. 그리미 버튼은 그대로 있고, 지호가 누른다.
7. 그리미(틀리는 해석자): "어? 난 이게 우산처럼 보이는데?"
8. **클라이맥스**: 지호가 고친다 — "아니야, 자전거 바퀴야!" 아이가 자기 그림의 저자로서 AI를 교정하고, 근거를 말한다. 추궁당한 것이 아니라 가르쳐 준 것이다.
9. 동화책 쪽 띠에 오늘 그림이 **3쪽으로 꽂힌다**.

실패 경로: 저장 중 오프라인 → IndexedDB 큐 보존, 안심 한 줄, 그리기 계속. 409 → 자동 재전송 없이 명시적 재시도 하나.

### Flow 2 — 서연(1학년, 비문해)의 첫 입장

1. 선생님이 보여준 학급 QR을 찍는다. 코드 입력 화면을 만나지 않는다.
2. 학생 입장 화면. 상단 음성 버튼 하나 — 누르면 확정 시나리오 문장이 이 화면에서 할 일을 처음부터 안내한다. **이것이 서연의 유일한 언어 채널이다.**
3. `새로 시작하기`(그림+큰 터치로 식별 가능) → 동물 10마리 그림 중 하나를 고른다.
4. 별명은 주사위 버튼으로 후보를 굴려 고른다 — 읽지 못해도 고를 수 있다.
5. 그림 비밀번호 3개를 그림으로 고른다.
6. **클라이맥스**: 글을 한 글자도 읽지 않고 자기 자리(동물+별명)가 생겼다. 학생 홈의 오늘 회차 카드 앞에서 음성 버튼을 누르면 오늘 그릴 장면을 태블릿이 말해 준다. 서연은 다른 아이들과 똑같이 시작한다.

실패 경로: 음성이 기기에서 안 나옴(Web Speech 편차) → 그림 표지와 큰 터치만으로도 같은 흐름이 완결된다(비문해 완결성 원칙).

### Flow 3 — 박선생님의 2회차 열기

1. 로그인 → 학급 화면. **맨 위 수업 조종석**이 문장으로 말해 준다: 아크 "자전거 이야기", 현재 1회차.
2. `다음 회차 열기`를 누른다 — 확인 대화상자 없이 즉시 실행된다(되돌릴 수 있으므로). 조종석이 2회차로 갱신된다.
3. 바로 아래 QR 패널을 크게 띄워 아이들에게 보여준다. 화면 순서가 수업 순서 그대로다.
4. **클라이맥스**: 아이들 태블릿이 다음 폴링에서 2회차 카드를 띄우고, 박선생님은 태블릿을 내려놓고 교실을 돈다. **두 번째 회차를 아무 도움 없이 스스로 열었다** — M-1이 재는 바로 그 순간.
5. 한참 뒤 돌아와 학생 그리드를 슬쩍 본다(간헐 확인). 타일에는 동물과 별명뿐, 세어야 할 숫자가 없다.

경계: 자유 그리기를 하던 아이가 있어도 그리던 그림은 강제 전환되지 않는다 — 다음 폴링에 안내만 나타난다.

### Flow 4 — 결석했던 하늘이의 재합류

1. 지난주(2회차)에 결석한 하늘이가 오늘 입장한다.
2. 오늘 회차 카드는 반과 똑같이 "3회차"다. 반 진도가 개인 진도를 이긴다(FR-5) — 밀린 것을 먼저 하라는 화면은 존재하지 않는다.
3. 하늘이는 오늘 장면을 그리고 완료한다. 3쪽이 꽂힌다.
4. **클라이맥스**: 쪽 띠에 2쪽이 점선의 빈 종이({colors.undrawn-fill} + {colors.undrawn-dash})로 보인다 — "아직 안 그린 쪽". 경고도, 숫자도, 낙서도, 재촉도 없다. 탭해도 아무 일도 일어나지 않는다. **빈 쪽은 부재이지 실패가 아니고**, 하늘이의 이야기는 오늘 그림으로 계속 이어진다.

경계: 빈 쪽을 채우는 경로(집, FR-10 계열)는 보류 — 이 흐름은 그것 없이 완결된다.
