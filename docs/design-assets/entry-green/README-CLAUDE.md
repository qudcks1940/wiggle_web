# Claude 전달용 — 초록 교실 입장 안내

## 확정 요청과 범위

- 사용자는 구현 전에 시안을 보고 싶어 했다. 이 묶음은 에셋 전달용이며 앱 코드를 수정하거나 배포한 결과가 아니다.
- 기준 시안: `reference/approved-green-palette-fixed.png`.
- 몽그리는 첫 진입 화면의 **노란 화가 오리**다. `/brand/grimi-mascot.png`의 구름 캐릭터가 아니다.
- 배경·문·테두리·글자의 파란색은 초록색으로 바꾼다. 오리 모자·스카프·붓끝·팔레트 색은 보존한다.
- 시안에서 팔레트가 손과 떨어져 떠 있던 오류를 고쳤다. 오른쪽 날개가 팔레트 가장자리를 실제로 잡는다. 팔레트와 손을 별도 이미지로 분리하지 않는다.

중요: `classroom-with-mongri` 위에 오리 이미지를 또 올리지 않는다.

독립 오리는 기존 정면 에셋이므로 수정 시안의 손 자세와 정확히 같지는 않다. 수정한 자세를 그대로 뽑은 투명 이미지 생성은 두 번 모두 체크무늬가 들어간 RGB로 나와 제외했다. 체크무늬 이미지를 투명 PNG로 전달하지 않는다. 시안의 수정 자세가 꼭 필요한 경우 완성 장면을 사용한다.

## 넓은 화면 배치 기준

기준 캔버스는 1672×941. 배경은 비율을 유지한다. 아래 수치는 시안에서 읽은 배치 가이드이며 브라우저 측정 결과가 아니다.

- 배경: 전체 캔버스. `object-fit: contain` 또는 동일 비율 부모에서 `width:100%; height:auto`.
- 로고: x 2.4%, y 3.2%. `Wiggle` 워드마크는 진초록 HTML로 구현. 기존 브랜드 아이콘을 재사용하되 **초록 아이콘의 별도 분리 파일은 이 묶음에 없다**. 전체 시안에서 로고를 잘라 낮은 해상도로 확대하지 않는다.
- 듣기: 오른쪽 2.4%, 위 3.3%. 기존 `SpeakButton` 동작 재사용.
- 문 간판 `우리 반`: x 21.3%, y 20.5%, 폭 12%, 높이 7%. 배경의 빈 간판 위 HTML.
- 오른쪽 안내 영역: x 48%, y 15%, 폭 48%. 제목은 시안처럼 한 줄로 들어갈 때만 한 줄. 좁아지면 자연스럽게 줄바꿈.
- 상태 안내: x 55%, y 38%, 폭 27%. 종이 느낌의 영역과 문구를 HTML/CSS로 만들 것.
- 주 행동: x 55%, y 52%, 폭 28%, 높이 약 10%.
- 도움 행동: x 55%, y 65%, 폭 28%, 높이 약 9%.
- 재확인: x 64%, y 77%.
- 오른쪽 아래 이젤과 텍스트/버튼이 겹치지 않도록 실제 화면에서 검사.

시안 재현용 비율 좌표가 작은 화면의 글자와 터치 영역까지 축소하는 근거가 되어서는 안 된다.

## 좁은 화면 제안

- 760px 이하 또는 높이가 짧은 화면은 크림 단색 배경 + 독립 오리 + 안내 + 행동의 정상 문서 흐름으로 전환한다.
- 독립 오리는 `width: clamp(140px, 42vw, 220px); height:auto` 정도에서 시작한다.
- 큰 교실 배경을 `cover`로 무조건 잘라 문·오리·안내가 사라지게 만들지 않는다.
- 버튼 높이는 48px 이상, 본문 16px 이상. 320×568·390×844·844×390에서 가로 넘침, 탭 초점, 문구 잘림을 직접 확인한다.
- 이 반응형 제안은 아직 사용자가 별도 선택한 모바일 시안이 아니다.

## 실제 HTML로 구현할 내용

제목: `몽그리랑 다시 찾아보자!`
설명: `수업 코드가 맞는지 한 번만 더 확인해 줘.`
상태: `수업을 아직 찾지 못했어요`
주 버튼: `수업 코드 다시 입력하기`
도움 버튼: `선생님, 도와주세요`
보조 행동: `다시 확인하기`
듣기: `들어 보기`
문 간판: `우리 반`

문구, 버튼, 아이콘, 로고는 이미지 한 장에 굽지 않는다. 음성 안내와 상태별 문장은 기존 제품 정책을 확인한다. 선생님 도움 버튼은 실제 메시지를 보내는 동작처럼 표현하지 말고, 손을 들고 선생님께 도움을 요청하는 안내로 구현한다. 코드 오류와 네트워크 오류를 구분하고 재시도 동작을 유지한다.

## 검수 결과와 한계

- 수정 시안과 최종 장면에서 손·팔레트 접촉을 눈으로 확인했다.
- 생성 배경에서 UI 문구/버튼과 간판 글자가 제거된 것을 눈으로 확인했다.
- 기존 독립 오리 PNG/WebP의 알파 채널 및 alpha 최소값 0을 파일 데이터로 확인했다.
- WebP는 PNG에서 sharp로 인코딩했으며 장면 내용이나 색상을 코드로 편집하지 않았다.
- 생성형 재구성으로 종이 질감·세부 윤곽이 기준 시안과 완전히 픽셀 단위로 같지는 않다.
- 앱 구현, 브라우저 반응형 검증, 운영 배포는 이 전달 묶음의 완료 범위에 포함되지 않는다.
