# 에셋 출처와 처리

- 사용자 선택: 번호 입력 화면의 2번 시안, 2026-09-09 명시 확정.
- 원본 참조: `exec-c67441b3-6c64-4c7b-837b-d12d05dbb2e3.png` (대화에서 생성한 시안).
- 생성 도구: 내장 `image_gen.imagegen`. 외부 API/CLI는 사용하지 않았다.
- 편집 프롬프트 정본: `prompts.json`.
- 배경: 선택 시안의 글자·로고·입력창·키패드·버튼을 이미지 편집으로 제거했다. 빈 스케치북과 초록 교실, 몽그리를 유지한다.
- 독립 오리: 선택 시안의 오리와 크레용을 참고해 모바일용 크림색 배경 일러스트로 재구성했다. 투명 에셋이 아니다.
- PNG를 보존하고 sharp로 WebP 변환·비례 축소했다. 코드로 이미지 내용을 재도색하거나 캐릭터를 합성하지 않았다.
- 생성형 편집이므로 세부 질감은 원본과 픽셀 단위로 같지 않다. 선택 시안을 비교용으로 포함한다.
- 생성 시안의 로고는 서비스용 로고가 아니다. 기존 프로젝트의 정식 로고를 사용한다.
- 메타데이터·파일 무결성은 manifest/ZIP 검수로 확인하며, 브라우저 통합 검증은 구현 후 수행한다.
