# 교사 화면 시안 피드백 (2026-09-07, 타 팀 시안 「내 학급」)

> 대상: 파랑 계열 「교사 공간 — 내 학급」 시안(학급 목록 + 학급 정보 수정 패널, 브랜드 "꿈틀").
> 정본 근거: `docs/bmad/planning-artifacts/ux-designs/ux-wiggle-web-2026-08-31/DESIGN.md`,
> `docs/product-decisions.md`, 아키텍처 AD-17.
> 레이아웃(좌측 내비 + 목록 + 우측 수정 패널) 자체는 좋다 — 아래는 확정 결정과 어긋나는 지점이다.

## 반드시 고칠 것

### 1. 팔레트 — 파랑 계열은 폐기된 방향이다
하늘색·파랑 시스템은 "너무 남성 아이 중심"으로 2026-08-31 폐기 확정,
Sunshine 초록·노랑 팔레트로 교체해 코드에도 적용됐다(커밋 a0c6a62).
시안의 파랑 토큰을 전부 DESIGN.md 토큰으로 치환할 것:

| 시안의 파랑 용도 | 교체 토큰 |
|---|---|
| 지면·카드 배경 | `page-ground` #F2F5EE |
| 주 CTA(변경사항 저장, 학급 만들기) | `action-yellow` #F6C84B + 글씨 `ink` #16220F — **노랑 위 흰 글씨 금지(1.6:1)** |
| 교사 앵커·강조(제목, 선택 행, 내비 활성) | `teacher-anchor` #2E5F23 |
| 연한 배경(선택 행, 배지) | `pale-field` #E4EFDC |

교사 화면은 아이 화면과 "같은 가족, 다른 말투"다(DESIGN.md § 교사 레지스터) —
장식을 줄이되 색 가족은 공유한다. 파랑을 교사용 별도 팔레트로 남기지 않는다.

### 2. "소속 학교 / 학교 정보 수정" — 수집하지 않는 데이터다
현재 제품은 학교명을 어디에도 수집·저장하지 않는다. 학생 학교명은 제품 불변 원칙상
**금지**이고, 교사 소속 학교도 확정 결정에 없는 신규 수집이다(개인정보 검토 필요).
결정 없이 시안에 먼저 넣지 말 것 — 해당 사이드바 블록은 제거.
필요하다고 판단되면 `docs/pending-decisions.md`에 항목으로 올려 사용자 결정을 받는다.

### 3. 학급 삭제 문구 — 부드럽게 바꾸면 안 된다
시안 문구 "목록에서 숨기고 입장을 종료합니다"는 결과를 축소한다.
확정(AD-17): 학급 삭제는 학생 입장·기존 로그인·가족 공유가 즉시 끝나고
아이가 자기 그림과 동화책을 다시 열 수 없는 동작이며, 문구는 이 사실을 그대로 말한다.
현재 운영 문구(테스트로 잠김, `tests/arc-teacher-view.test.mjs`):

> 되돌릴 수 없어요. 학생 입장과 기존 로그인, 가족 공유가 즉시 끝나고
> 이 학급 아이들은 자기 그림과 동화책을 다시 열 수 없어요.

반대로 **아크 회차 전환·재열기에는 겁주는 문구·confirm을 쓰지 않는다**(정상 동작, FR-2a).
"되돌릴 수 없다"는 삭제에만 쓴다.

### 4. 아크 조종석이 없다
교사 화면의 최상단 핵심은 "오늘 회차 열기"(아크 조종석)다.
이 시안이 학급 관리 단면만 다룬 것이라면 문제없지만, 교사 공간의 전체 IA라면
「내 학급」 위(또는 학급 상세 진입 직후)에 조종석이 와야 한다 —
현행 구현 참조: `app/components/TeacherApp.tsx`의 `ArcCockpit`.

## 권장 (막지는 않음)

- **브랜드 "꿈틀"**: 신규 네이밍이면 미결정 사항이다 — 확정 전까지 시안에 로고를 박지 말고,
  확정하려면 `docs/pending-decisions.md`에 올릴 것.
- **검색창**: 학급 4개 규모에 검색은 과하다. 실사용 교사는 학급 1~3개다 — 제거 권장.
- **"수업 코드는 학급 안에서 관리합니다"**: 맞는 방향. 단, 수업 코드·QR은 입장 수단일 뿐
  작품 접근 권한이 아니라는 원칙(제품 불변)이 문구에 스며들면 더 좋다.
